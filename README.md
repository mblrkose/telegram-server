A simple telegram file storage bot.

A simple website made in html, css and js.
All you need is create a channel and a bot. Enter their ID and Token and just you have to do is upload a file.

Here is the step of getting the ID and the Token:

1. Get BOT_TOKEN
  Open Telegram
  Search @BotFather
  Press Start
  Send:
  /newbot
  Enter bot name (any name)
  Enter bot username (must end with bot)
  Copy the token BotFather gives you

✅ This is your BOT_TOKEN

2. Get CHAT_ID (for yourself)

  Search your bot and press Start
  Send any message (example: hi)
  Search @userinfobot
  Press Start
  Copy Your user ID

✅ This number is your CHAT_ID
